# 🍽️ Restaurante Sabores de Chile

Proyecto desarrollado para la asignatura **Programación Web I – Semana 7** del Instituto Profesional IACC.

El sitio web corresponde a una propuesta responsive para un restaurante de gastronomía chilena, aplicando técnicas modernas de desarrollo web como **Responsive Design**, **CSS Grid**, **Media Queries** y enfoque **Mobile First**.

---

# 📚 Objetivo del Proyecto

Desarrollar una página web adaptable capaz de visualizar correctamente su contenido en distintos dispositivos:

- 📱 Smartphones
- 📲 Tablets
- 💻 Computadores de escritorio
- 🖨️ Medios de impresión

---

# 🚀 Tecnologías Utilizadas

- HTML5
- CSS3
- CSS Grid Layout
- Media Queries
- Responsive Design
- Mobile First
